    Field legend

    SON stores metric values from each provider. The same field can mean different things by site type.

    SNOTEL / SCAN / MSTL (NRCS)

    • SWE — snow water equivalent (pillow)
    • Snow depth — depth at the sensor
    • Temperature — observed air temp
    • Precipitation — water-year accumulation (usually from Oct 1), not this hour’s rain
    • Snowfall / wind / humidity — usually not provided

    BC ASWS

    • SWE — snow water equivalent
    • Snow depth — depth at the pillow
    • Temperature — air temperature
    • Precipitation — seasonal / water-year accumulation, not hourly rainfall
    • Snowfall / wind / humidity — not in these CSVs

    JMA AMeDAS

    • SWE — not available (always blank)
    • Snow depth — current snow depth
    • Snowfall — last 1 hour of snowfall
    • Temperature — air temperature
    • Precipitation — last 1 hour of rain/melt (not a year total)
    • Wind / humidity — when reported

    The API always stores metric (°C, mm, cm, m). Use the Metric / US switch to display °F, inches, and feet in the UI.
